# 多様化学習前の研究根拠

更新日：2026-09-07（JST）。対象は黒背景のCG。実在CADは1194Mのみで、模型・実画像・スケジュールは今回の検証範囲に含めない。

## 問い・主仮説・貢献の候補

主仮説：同じ画像枚数・更新回数・CNN・後処理で比較したとき、外観多様化に形状多様化を加えると、定義した合成PAF形状族の未学習形状に対する正しい上端内周検出率が改善する。

この仮説は、外観拡張のみのBと、形状も拡張したDの差で反証できる。DがBを改善しない場合、形状多様化が必要という主張を採用しない。

貢献の候補は次の3点。いずれも多様化学習の結果が出るまでは実証済みの貢献とはしない。

1. PAF内周の意味的な抽出について、画像上の内周寸法をそろえた形状変化の影響を、抽出と楕円推定に分けて示す。
2. 同じ学習予算の2×2実験で、外観多様化に対する形状多様化の追加効果を分離する。
3. 補間・外挿・別断面と撮像条件の変化を分け、形状多様化や幾何手法が有効な範囲を示す。

新しいCNN構造、CNNとRANSACの接続、形状ランダム化の発想そのものを新規性とはしない。主張対象は合成形状族内の検出であり、実在PAF全般、任意の宇宙機、実画像、軌道環境、6自由度姿勢、接近制御・捕獲成功・安全性には拡張しない。

使用する事前情報は、対象部位が上端の円形内周であることと、PAFが画像内にあること。実径・詳細CAD・正解輪郭は画像生成と評価にのみ使用し、通常のCNN推論には渡さない。Canny統制は同心・相似な輪郭対の事前情報も使うため、完全に同じ事前情報の比較ではない。

## 既存CNNの診断結果

入力：`parametric_paf/output/comparison/` の元画像・正解。現行1194M学習済み重みは変更していない。
出力：`parametric_paf/output/diagnosis_v1/`。重点3モデル144画像と1194M参照48画像、計192画像。各画像でRANSAC seedを5通り、正解近傍抽出点oracle、理想投影点oracle、Canny・Zhang候補を保存した。

|形状|通常CNN成功数（5 seed、各48枚）|正解近傍点oracle|理想投影点oracle|完全内周の支持被覆平均|
|---|---|---:|---:|---:|
|baseline|44 / 42 / 42 / 43 / 44|45/48|48/48|70.1%|
|low_taper|23 / 22 / 21 / 23 / 21|41/48|48/48|56.3%|

成功は診断互換用IoU≥0.8。支持被覆は、完全な正解楕円の720等パラメータ角標本のうち、確率≥0.35の抽出画素が2px以内にある割合。可視性・照明コントラストとは別の指標。

重点3モデルの全144画像を、成否で選別せず視点別24シートで確認した。`sheets/`、全画像の `panels/`、`arrays/`、`records/`、`classification.csv` が対応する。画像パネルは左上：原画像＋正解緑/通常推定赤、右上：確率マップ、左下：Canny、右下：正解近傍点oracle。

### 失敗の一次分類

|形状|抽出不足・偏り／短い弧からの復元困難|競合反応を含む点群でのフィット・選択への感度|既知の別境界全体に一致|幾何学的にほぼ不可視|IoU成功|
|---|---:|---:|---:|---:|---:|
|baseline|3|1|0|0|44|
|low_taper|7|18|0|0|23|
|thick_wall|11|7|0|0|30|

分類はseed offset=0の47失敗について、明示した操作的規則に基づく。正解近傍2pxの抽出点だけで成功する失敗を「フィット・選択への感度」、それでも失敗するものを「抽出不足・偏り／短弧復元困難」とする。「別境界全体に一致」は、生成器が投影する上端外周・底面内周・下端外周のいずれかにp95≤2pxで一致する場合。0件は別境界への局所的な反応がないことを意味しない。複数境界や局所弧を混ぜた誤楕円もある。

oracle成功は、正解を知らない通常方式で復元可能であることを保証しない。oracle失敗も抽出だけに原因があることを証明せず、短弧のフィット不安定性を含む。この分類を単一原因の確定診断として扱わない。

### 生成・正解・陰影の確認

- 3形状×8視点の投影をBlenderで再計算し、保存済み192頂点の正解と最大誤差1e-3px以下で一致。ray castでは各上端内周の全192頂点に手前の遮蔽物がない。これは幾何学的可視性であり、暗部や同色境界の識別可能性を保証しない。
- 材料と光源方向を固定した対応比較でlow_taper/thick_wallの低下が残り、5 seedでもbaselineと成功数範囲が離れている。H1はこの開発CG条件での**形状変更の総合効果**として支持される。高さ変更による底面・影の変化を含み、輪郭の幾何形状のみの因果効果ではない。
- 大きい面光源で影を緩和した24画像を補足描画。固定光源方向60°/0°の8視点では、元Sun条件→面光源条件の成功数がbaseline 6→4、low_taper 2→1、thick_wall 3→2。全体にコントラストも変わるため、純粋な「影だけ」の介入ではない。面光源で形状依存が解消した証拠はなく、撮像条件への依存も残る。
- 理想点のRANSACは全192画像で成功。現在の証拠からラベル生成や共通RANSACの一律の幾何破綻は認められない。競合点での選択問題は残るが、正解を通常推論に使う変更や、形状ごとの後処理調整は行わない。2×2では同じ後処理を固定し、抽出の支持被覆も併記して効果を分ける。

再現上の注意：既存比較表のlow_taperは24/48、今回の現環境再実行は23/48。`c70_000_l60_000` が旧IoU 0.831281から今回0.705410となる。今回の確率マップと同seedの推定は追加3回で一致した。旧provenanceにはコード全体とライブラリ版がなく、過去との差の原因は未特定。旧記録を置換せず、今回の値は `diagnosis_v1` と区別する。現在の診断にはコード・画像・設定・重みのhashと主要ライブラリ版を保存している。

## 評価定義の固定根拠

主成功条件はIoU≥0.80かつ双方向輪郭距離p95≤2.0px（256入力）。IoUのみの成功率も互換指標として残す。
輪郭は各楕円を720の等パラメータ角で標本化し、相互の最近傍距離を連結して平均・95百分位を計算する。等弧長標本ではない。距離は画素と正解長径比の両方を保存する。

2pxは既存RANSACの許容距離と整合し、教師リング幅3pxに対して輪郭位置を評価する基準。開発3形状×8視点で、正解と既知の別境界のp95距離は最小6.074pxであり、2pxで別境界全体を許容しないことを確認した。根拠は `diagnosis_v1/boundary_calibration.csv`。テストを見て閾値は変えない。捕獲用途の安全許容値ではなく、解像度や別境界間隔を変えた実験には無条件で転用しない。

この主指標で現行重みを開発画像に適用するとbaseline 17/48、low_taper 10/48、thick_wall 0/48。IoUのみの成功が正しい輪郭位置を必ずしも意味しないことを示す。新指標での多様化学習による改善は未検証。

対象ありでは「正解成功」「未検出」「誤楕円出力」を全画像を分母に分ける。対象なしの黒画像・穴なし円盤での誤検出は別集計。未検出の距離を0にせず欠測として残し、検出例だけの誤差には分母を明記する。

開発用の対象なし診断（`paf_shape_appearance_v1/development_absent/` と `diagnosis_absent/`）では、現行1194M学習済みCNNは黒画像1枚・穴なし円盤1枚の双方で楕円を出力した。Cannyは円盤で、Zhang 2019型（再現実装）はいずれも未検出。少数例なので率の推定には使わないが、対象がない画像を含む一般的な探索性能を主張できない具体例である。この診断はvalidation由来の条件を使い、最終対象なしテストとは別に扱う。2×2の学習対象はPAFが画面内にある条件に固定し、対象なしの結果は補足として残す。

## 幾何手法の調整

最終テストと分離した共通validation 8形状×24条件＝192枚に対し、Canny閾値30/90・50/140・80/200を両手法で比較。その他の構成は固定。全1,152推定を `paf_shape_appearance_v1/geometry_validation/results.csv` に保存。

|手法|30/90の主成功数|50/140|80/200|採用|
|---|---:|---:|---:|---|
|Canny＋輪郭別RANSAC|129/192|126/192|126/192|30/90|
|Zhang 2019型（再現実装）|116/192|114/192|108/192|30/90|

選択順は主成功数、IoU成功数、標準設定50/140、候補index。これは限定した合理的調整であり、最適な幾何手法の探索ではない。学習条件やテスト形状ごとに設定を変えない。

## 学習へ進む判断

生成・ラベルの明白な破綻を原因とする証拠はなく、形状変更に伴う抽出・推定の低下が複数seedで残る。次に操作する要因は、**CNN構成・後処理を固定した学習形状と外観の多様性**とする。
実行仕様は [README.md](README.md)、固定値は [protocol.json](protocol.json)、全形状は [shapes.json](shapes.json)、撮影条件は [conditions.json](conditions.json)。学習効果、未学習形状の最終成績、実画像への汎化はまだ結果ではない。
