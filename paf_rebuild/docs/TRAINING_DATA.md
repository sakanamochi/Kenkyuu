# 学習入力・教師・損失の仕様

設定は`configs/training_data.json`、入力生成は`src/training/data.py`、教師と損失は`src/training/objective.py`。既存の画像・ラベル・manifestを参照し、旧Python実装は実行時にimportしない。CG生成と重みの更新処理はこの範囲に含まない。

## 学習元と分割

|項目|1194M|多様形状|
|---|---|---|
|trainの例数|1,988|1,988|
|validationの例数|735|735|
|学習用4スロット|元投影・元材質を2枠、拡張投影・元材質を2枠|元投影・元材質、元投影・外観変更、拡張投影・元材質、拡張投影・外観変更|
|validation|1194Mの元画像・固定劣化|多様形状の元画像・固定劣化|

各スロットの抽選確率は25%。1epochの例数は4倍にしない。同じ画像を指すスロットはキャッシュを共有する。設定の相対パスは設定ファイルの場所を基準に解決する。学習元は呼び出し時に明示し、多様形状の入力へ1194Mを混ぜない。

`sample_id`・`group_id`・劣化条件・劣化seedが全ビューで対応することを要求する。確認入口ではtrain・validation・testの群の非重複と、使用可能な全ビューの画像・ラベルhashを照合する。

## 入力と教師

対応する元画像は480×480のuint8、ラベルは同じ画像の内周投影点。固定劣化を適用してモノクロ256pxへ縮小し、同一輝度を3chに複製して[-1,1]へ正規化する。白飛び倍率は1。発表用の強化評価に用いる倍率2を学習へ適用しない。

穴領域は正解内周頂点へ楕円を当てはめ、256pxでアンチエイリアス付きの内部領域を描く。可視マスクは矩形に覆われた領域だけを0とする。2chの教師素材から、3×3の膨張と収縮の差で幅約2pxの境界を作り、可視マスクを掛ける。白飛び・黒つぶれによる境界の見え方は教師から除外しない。

trainの矩形遮蔽例だけは、選択したビューの原画像と正解楕円を用いて遮蔽位置を毎回再抽選する。開口の横方向半幅をh、中心をcx、抽選値をuとし、矩形の縦辺を`round(cx + (2.5u - 1.25)h)`で定め、1〜画像幅−1に制限する。画像と可視マスクの同じ領域を原解像度で覆ってから縮小する。正解楕円は学習データ生成にのみ使用し、推論へ渡さない。

## 乱数と損失

学習seedを明示的に渡し、ビュー抽選はseed＋5200、遮蔽抽選はseed＋6200の独立したNumPy Generatorを使う。4スロットの抽選、遮蔽の左右、遮蔽位置の順序を固定する。validationではこれらの抽選を行わない。DataLoaderは`num_workers=0`に限定する。

損失は正例重み12のBCEWithLogitsLossと、画像ごとに計算して平均したDice損失の和。Diceの平滑化定数は1。`boundary_loss(logits, masks, positive_weight=12.0)`の引数で正例重みを指定する。`training_data.json`は入力生成だけを設定する。空の境界教師も通常の学習例として含める。

## 確認方法と範囲

`scripts/check_training_data.py`は全5,446例をmanifest順に読み、入力・穴領域・可視マスク・可視境界を検査する。抽選seedの既定値は20260907。出力フォルダの`verification.json`には実装・入力のhashと配列列のhashを保存する。再実行時は新しい出力フォルダを指定する。

確認済みの数値・根拠ファイル・未検証範囲は[HANDOFF.md](HANDOFF.md)にまとめる。
