# 1194Mの外観変更なし・投影拡張ありの比較

1194M側は元の材質を使い、投影拡張を残す。多様形状側は採用済みの外観・投影拡張を維持する。教師・中心線RANSAC・遮蔽/白飛び/黒つぶれ・損失・最適化・60epoch・3seedは固定する。

外観変更は材質の反射色へノイズ・縞・格子を加える処理。投影拡張はカメラ条件を変更して画像上の内周の大きさ・位置・扁平率を変える処理。どちらもCADの形状を変更しない。この対照では1194Mの色・模様の乱数化だけを外す。投影に伴う陰影の変化や、元データに含まれる照明条件の違いは残る。

|項目|1194M学習CNN|多様形状学習CNN|
|---|---|---|
|元投影・元材質|50%|25%|
|元投影・外観変更|0%|25%|
|拡張投影・元材質|50%|25%|
|拡張投影・外観変更|0%|25%|
|教師・推論・最適化|共通|共通|

1194Mの4ビュー抽選を`[0,0,2,2]`へ対応させる。抽選回数・投影の抽選列・遮蔽乱数を保ち、外観ビットだけを除去する。元比較の元材質画像をそのまま参照するため、新しいCGの描画は不要。validation/testの画像・選択規則は同じ。

この比較では外観拡張の有無が両学習元で異なる。1194Mの外観変更あり/なしの対照は外観拡張だけの変更であり、両CNNの比較は学習データ源と外観拡張の設定を含む比較として扱う。

## 実行と構成

`no_surface.py/json`が学習元とビューの対応を指定する入口。既存の共通学習・評価関数を呼ぶ。`no_surface_report.py`は全件監査、外観変更あり/なしの対応比較、条件別順位、図、バックアップを作る。共通教師・CNN・RANSAC自体のコードは変更しない。

```powershell
.venv/Scripts/python.exe -X utf8 research/paf_fair_comparison/no_surface.py check
.venv/Scripts/python.exe -u -X utf8 research/paf_fair_comparison/no_surface.py run --sources 1194m
.venv/Scripts/python.exe -X utf8 research/paf_fair_comparison/no_surface_report.py report
.venv/Scripts/python.exe -X utf8 research/paf_fair_comparison/no_surface_report.py snapshot
```

保存先は`output/paf_1194m_no_surface_v1/`。以前の外観変更あり比較は`output/paf_fair_comparison_v1/`とその確定snapshotに保持する。多様形状の全推定と固定幾何はhashを検証して再利用し、1194Mを3seed学習・両testで評価する。

主指標はIoU≥0.8の成功率、全画像を分母に含む。通常＋3劣化×4強度の13条件を両testで比較し、平均と各seedを示す。投影を維持した外観変更あり/なしの差は、同じseed・同じ画像で対応付ける。既存testは参照済み、黒背景・単一開口CGという範囲を維持する。

## 確認済みの結果

各3seed・60epochの学習と両test評価が完了。1194Mの採用epochは28/34/49で、各学習元のvalidation loss最小を用いる。成功率はIoU≥0.8、通常＋3劣化×4強度の全13条件平均。

|評価集合|①1194M学習・外観なし|②多様形状学習|Canny＋輪郭別RANSAC|Zhang 2019型（再現実装）|
|---|---:|---:|---:|---:|
|1194M|81.87%|71.34%|49.18%|46.91%|
|多様形状|58.16%|74.84%|53.00%|61.24%|

全体順位は各seedでも同じ。1194Mでは①>②>両幾何、多様形状では②>Zhang>①>Cannyとなり、「多様形状で②>③>①」はZhangには成立するがCannyには成立しない。多様形状の平均IoUは②0.7145>①0.6616>Zhang0.5651>Canny0.5358で、成功率と順位が異なる。

①の外観変更あり対照からの差は、1194Mで81.64%→81.87%（+0.23 pp）、多様形状で56.78%→58.16%（+1.38 pp）。対応する画像群bootstrap 95%区間はそれぞれ−0.16〜+0.62 pp、−0.40〜+3.25 ppで、どちらもゼロを含む。固定3seedでの画像群の不確実性であり、学習seed母集団は含まない。外観除去の一般的な改善効果とは結論しない。

通常画像の①は1194M100.00%、多様形状79.22%。半画面遮蔽では①95.54%/37.66%、②72.92%/68.40%（1194M/多様形状）。1194Mの黒つぶれ0.75は①98.81%/②66.67%、1.0は①69.64%/②20.54%で、専用学習との差が残る。遮蔽1.0は両集合の全方式0%、多様形状の遮蔽0.75も全方式0%で、全条件で厳密な順位が成立するわけではない。

全38,038推定の元GT再照合、384学習入力の対応、3,976組の教師・劣化条件一致を確認済み。図の150表示値（通常の再表示を除く130条件値）は集計から生成し、図の目視も確認した。
