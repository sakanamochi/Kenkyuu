# 汎化に効いた大きな変更を絞るPAFの対照実験

更新日：2026-10-25（JST）。全4構成・全3seedの学習・評価・照合を完了。現在の基準はhole-region-comparisonの最終候補の可視境界CNN＋中心線RANSACであり、mainへの完全一致を要求しない。

追加の[固定1seed・学習時間の診断](../paf_training_diagnosis/README.md)では、同じ連続学習の60/120epochで拡張なし43.20/46.22%、投影のみ40.80/43.41%、投影＋外観70.95/69.78%（1194M全条件）。投影のみは延長で回復するが、同予算の基準との差は残る。以下は保全した60epoch・3seedの要因比較であり、追加1seedの数値と混ぜない。

## 結論と採用構成

**形状を多様化するだけでなく、内周の投影と外観の偏りを同時に減らすことが、学習に含めない1194Mへの転移を大きく改善した。** これを卒論の主な答えにする。CNN内部で抽象的PAF概念を獲得したという主張ではない。

主要な変更は投影＋外観の学習分布で、1194M全条件は43.20→69.30%（+26.10pp）。外観だけでは56.94%、投影だけでは38.19%であり、両方を残す。可視境界教師・中心線RANSACはmainの小さい開口の問題を踏まえた共通基礎とし、この2×2比較の要因には含めない。

運用には既存の`boundary_projection_relative`を採用する。投影＋外観に、開口幅を基準とした遮蔽再抽選を加える単一CNNである。遮蔽再抽選の全条件差は+2.11ppだが、半画面では1194Mで+7.74pp、多様形状で+13.64ppと大きく、欠損耐性という目的に照らして残す。これは学習データの規則で、推論処理を追加しない。モデル統合・対象別閾値・新しいネットワークは不要。

採用構成の全条件成功率は1194M71.41%、多様形状74.86%。固定Cannyは49.18/53.00%、Zhang 2019型（再現実装）は46.91/61.24%。通常・白飛び・中程度の黒つぶれ・半画面遮蔽では高い性能を得たが、強い黒つぶれはmain構成の専用学習CNNとの差が残る。全条件で専用学習と同等とは結論しない。

## 研究の問いと仮説

問いは「特定機体の詳細CADを学習に使わず、多様形状のみで学んだCNNが、未知1194Mでも働き、画像劣化に固定幾何方式より強くなるために、何を変える必要があるか」。最高値を更新するための細かい追加を避け、少数の大きな変更に絞る。

仮説は「形状の種類だけでは内周の投影・外観の偏りが残り、これらを学習時に変えることで、対象固有の見え方への依存を緩和できる」。推論構成を共通にして、投影と外観の効果を対応比較する。開口幅遮蔽は既存の対応3seed比較から追加寄与を判断する。

## mainと最終候補の基本部分

[比較表](../../output/paf_core_ablation_v2/CORE_COMPARISON.md)と`core_comparison.json`を参照する。mainの基準commitは`088c4b6628916ece5822e1c8cb852cad76e9367f`。

CNNは同じTiny U-Net16・482,737パラメータで、クラス定義が一致する。重み付きRANSACの主要6関数も一致する。一方、mainの幅3pxの完全リング教師・閾値0.35の帯点群・最小45点に対し、最終候補は可視境界教師・閾値0.5の中心線点群・最小12点を使う。したがって、基本構成は同じだが検出器全体は同一ではない。CNNと幾何の併用を今回新しく追加した方法として扱わない。

正しいmain教師を直接RANSACへ渡す通常画像の診断では、1194M112例で100%、多様形状154例で58.44%。長径24px未満44例は11.36%。同じ閾値0.35・最小45点で中心線化すると、多様形状は98.05%（小さい開口93.18%）。中心線・最小12点では99.35%（小さい開口97.73%）。帯のまま最小12点へ変更しても58.44%。幅を持つ点群を扱う処理のサイズ依存が大きく、最小点数だけでは説明できない。これはGT教師の診断であり、CNN性能・運用成績・厳密な上限ではない。

固定ピクセル幅の誤差が小さい開口で厳しくなることは、同心円の例で説明できる。正解半径rに対して推定半径がr+δ（δ≥0）なら、面積IoUは`(r/(r+δ))²`。δ=1.5pxではr=10pxで約0.756、r=50pxで約0.943となる。これは尺度依存の説明用計算で、実際のRANSACの誤差が常に1.5px・外向きであるという測定結果ではない。

ユーザーの指示に従い、小さい開口への処理が確立した最終候補を共通基礎にする。mainへ戻した構成の探索は現在の主比較にしない。

## 手法を説明するための共通構成

検出対象は、このデータ生成器が定義する単一開口の上端内周。対象固有のCADを分類するのでなく、その境界位置をCNNで推定し、完全楕円の整合を既存RANSACで求める。「可視境界教師」は完全な可視性判定ではなく、穴領域から作った約2pxの境界から既知の矩形遮蔽だけを除く教師である。白飛び・黒つぶれによる情報残存は教師生成時に判定しない。

学習分布への介入は次の二つを主比較にする。

- 投影：開口の長径24〜180px（256画像上）、中心位置は幅・高さの0.3〜0.7、軸比0.1〜1.0を指定し、カメラの視点・焦点距離・シフトで描画する。開口が画像内に残るよう制限し、元の小さい開口の画像も半分残す。
- 外観：同じ形状にノイズ・縞・格子の反射色模様を与え、元材質と半分ずつ混ぜる。平均反射色も変わるため、純粋なテクスチャだけの実験とは呼ばない。

両方ありでは元/追加投影×元/追加外観の4ビューを等確率で抽選する。形状の種類、1epochの例数、CNN、損失、推定器は増やさない。投影による内周の画素長径と実寸穴径の相関は元trainの0.622から追加投影の-0.004へ変化している（497形状の生成結果、`data_audit.json`）。これは描画で偏りを緩めた事実であり、CNNがその相関を利用していた証明ではない。

遮蔽耐性の追加比較では、学習時の矩形境界を画像幅でなく開口の横幅から抽選する。これは学習時だけ正解形状を使うデータ生成規則で、推論時に正解や新しい処理を追加しない。投影・外観の主比較と区別して寄与を示す。この対照では固定遮蔽からオンライン再抽選にも変わるので、開口幅の基準だけの単独効果ではなく「開口幅を基準とした遮蔽再抽選」の効果として解釈する。

## 表面模様の採用根拠と確認できた範囲

採用する模様はノイズ（不規則な濃淡）、縞（方向性と周期性、うねりを含む）、チェッカー（格子状の濃淡）。Blenderの標準手続きテクスチャを物体座標から反射色へ接続する。凹凸・形状・カメラ・光源を模様追加のために変えない。画素へのセンサーノイズ追加とは異なる。模様の細かさ・位置・濃淡を抽選し、縞は方向・歪みも抽選する。各学習形状に一つの条件を固定し、epochごとに模様自体を生成し直してはいない。497学習形状中の内訳はノイズ163、縞171、チェッカー163。元材質と模様ありを50:50で用いる。

[実際の対応画像](../../output/paf_core_ablation_v2/figures/surface_examples.png)は各種類の固定train順の先頭。上下は同じ形状・撮影・光源、列間では形状が異なる。`surface_examples.py`が保存済み入力を読み、正解楕円・入力hashを照合してPNG/SVG/JSONを生成する。元入力と同じモノクロ256、全パネル固定濃度、露光補正なし。目視確認済み。模様別の性能を比べた図ではない。

方針の出典は[Tobin et al., 2017](https://arxiv.org/html/1703.06907v1)の非写実的なテクスチャによるdomain randomization。同論文III-Aはランダム単色・グラデーション・チェッカーを用い、IV-Cはテクスチャ多様性の寄与を調べる。本研究のノイズ・縞・チェッカー3種や数値範囲をそのまま推奨する研究ではない。[Geirhos et al., ICLR 2019](https://arxiv.org/abs/1811.12231)はImageNet分類CNNのテクスチャ依存と学習データによる変化を示すが、本研究のPAF検出CNNの内部表現を測ったものではない。

3種類の選択は、少ない実装で不規則・方向性・格子の濃淡変動を作るための設計判断。実機PAFの材質を再現する根拠や、各種類の必要性・3種の最適性を示す実験はない。全3seedで確認したのは、この外観変更一式の効果（元分布43.20→56.94%、投影あり38.19→69.30%）である。模様だけでなく平均反射色・コントラストも変わるので、模様自体が改善の原因とは断定しない。必要性を切り分ける追加対照としては、模様を付けず同程度の反射色の明暗だけを変える比較が重要で、現時点では未実施。

## 学習分布・比較の解釈

対応ビューのtrain/validationで、形状・劣化・投影教師5,446条件の一致を確認済み。元trainの内周長径は13.81〜90.09px、1194M testは99.65〜142.65pxで非重複。追加投影24.20〜179.02pxは元画像と混合し、小さい開口も保つ。統計は継承されたカメラ条件欄でなく描画頂点から算出する。

投影はカメラ条件によるサイズ・位置・軸比をまとめた一要因で、個々の寄与を証明したとは言わない。光源・材質の設定を保っても視点の変更で画素上の反射や明暗は変わり得るため、純粋な画像サイズだけの効果ではない。表面模様は反射色の明暗も変えるので、平均輝度を固定した純粋なテクスチャ効果ではない。全強度・全画像を分母に含め、通常・半画面遮蔽・白飛び0.5・黒つぶれ0.5を中心に比較する。既存testは参照済みで、新規盲検ではない。実画像・任意対象への汎化や抽象的PAF概念の獲得は未証明。

幾何比較はCanny＋輪郭別RANSACとZhang 2019型（再現実装）に限定する。元ラベル照合済みの6,916推定を共通画像で使用し、幾何一般への優位性とはしない。

main互換1194M学習CNNとの強い黒つぶれの差は残る。同じseed07で、強度0.75はmain参考95.54%に対して投影＋外観62.50%・開口幅遮蔽追加66.07%、強度1.0は65.18%に対して15.18%・18.75%。main参考は1seed・別教師・別学習率の比較で単一要因効果ではないが、通常や強度0.5の近さを全条件へ拡張できないことを示す。強い劣化を一括して「情報消失」とみなし分母から除かない。最小構成の判断ではこの限界も明示する。

強い黒つぶれの説明図は`exposure_cases.py`と[strong_black_crush_cases.png](../../output/paf_core_ablation_v2/figures/strong_black_crush_cases.png)。各強度で専用学習成功・最終候補失敗の固定順先頭を表示する。露光補正しない入力と予測確率から、内周応答が残っていても別の輪郭へ楕円が合う例を確認できる。2例の条件付き表示で、全体頻度や内部機構の証明ではない。

## 1194M通常画像での専用学習との小差の原因

①main構成の専用学習は通常112例中109成功（97.32%）、②採用多様形状モデルは各3seedとも111成功（99.11%）。①の失敗3例は斜めから見た扁平楕円で、短径の正解17.65/16.33/16.33pxに対して推定21.84/20.23/20.45px、IoUは0.7997/0.7861/0.7961。中心位置はほぼ合い、短径の過大推定で成功閾値0.8を下回る。

`clean_gap_diagnosis.py`は①の固定CNNで通常112例を再推論し、同じ確率・閾値0.35・最小45点・乱数seedのまま、RANSACへ渡す点を帯全体/中心線で比較する。元の帯推定をIoU誤差0で再現。中心線化だけで112/112成功、平均IoU0.9394→0.9930となり、失敗3例のIoUは0.9912/0.9702/0.9790へ改善した。結果と全例は`clean_gap_diagnosis/results.json`、[全失敗例の図](../../output/paf_core_ablation_v2/clean_gap_diagnosis/normal_failure_cases.png)。図の中列と右列のCNN確率は同一で、表示は内周付近の共通範囲。目視確認済み。

今回の通常画像の逆転は、①の帯点群処理で楕円が太くなることによって説明でき、多様形状学習の方が1194M学習より優れたためとは解釈しない。これは通常画像だけの事後診断で、学習元の単独効果を分離した比較や劣化条件での改善保証ではない。元の評価値・採用モデル・推論コードは変更しない。学習元だけの比較には教師・点群処理・学習条件を揃えた対照が必要。

## 卒論の流れと先行研究

既存CNNの対象依存→投影・外観の学習分布の偏り→少数の要因を変える仮説→基礎を固定した対応比較→両対象・劣化別の結果→必要な変更と限界、の流れにする。結果に合わない対照を省かず、変更を足した順番だけで寄与を決めない。

[Domain Randomization（Tobin et al., 2017）](https://arxiv.org/html/1703.06907v1)は、物体・背景の外観やカメラ条件などを変えた合成画像から実画像への転移を扱う（III-A、IV-C）。対象物体のメッシュを用いた位置推定であり、本研究の未知PAF内周検出とは課題が異なる。同論文でも要因の寄与を除去対照で調べており、カメラ変動の効果をすべての課題で大きいと保証していない。本研究ではこの着想に沿い、推定器を固定して投影・外観の寄与と組合せを測る。CG間の転移結果を実画像への転移成功とは呼ばない。

[Geirhos et al., ICLR 2019](https://arxiv.org/abs/1811.12231)は分類の形状・テクスチャ依存を調べた。本研究はその競合刺激による測定ではなく、外観介入で性能が上がっても形状理解を証明しない。

[Le Gentil et al., 2024](https://arxiv.org/html/2409.15581v1)はLM-MAPの反射リング・マーカーをCNNで強調し、二値化・細線化・楕円当てはめを経て姿勢推定する（II-A〜D）。外観を変えた物理模擬機での学習も扱う（III-B、C）。CNNと幾何の併用、中心線化、外観を変える着想を本研究固有の新規性として扱わない。同研究は既知のポート幾何・反射構造を使う6自由度推定で、本研究は評価機体固有CADを学習に使わない合成PAFからの2D内周検出を扱う。

本研究で示す点は「新しいCNNを作った」ではなく、**対象固有CADを学習に使わないPAF内周検出で、学習分布のどの少数要因が未知対象への転移と劣化耐性に必要かを、共通推定器の対照実験で明らかにすること**。この位置づけは着想の出典と実験の検証対象を区別したもので、一般的なPAF概念の獲得や先行研究全体に対する優位性は主張しない。
