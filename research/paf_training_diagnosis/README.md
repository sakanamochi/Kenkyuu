# 投影と学習時間の原因診断

追加実験はユーザー指定によりseed20260907の1つだけを使う。既存3seed平均は保存し、この診断の1seed値と混ぜない。既存候補の教師・検出器・重みは変更しない。

問いは「1194M学習CNNの多様形状への改善を何が説明するか」「多様形状学習の投影のみの悪化は学習不足か」。研究の目的は、対象固有CADを使わないPAF内周検出に必要な少数の学習要因を、共通推定器で切り分けること。

## 確認済みの答え

全て固定seed20260907。通常＋遮蔽・白飛び・黒つぶれの全13条件、成功はIoU≥0.8。追加4モデルの学習と7つの予算別checkpointの評価が完了した。

1194M学習CNNの多様形状への改善には、点群処理と投影拡張がそれぞれ寄与した。

|1194M学習モデルの構成|多様形状での全条件成功率|
|---|---:|
|旧main構成・帯45点|14.89%|
|旧CNNの重みを固定し、現行推論へ変更|27.57%|
|現行学習・投影なし・外観なし|42.91%|
|現行学習・投影あり・外観なし|56.74%|
|現行学習・投影あり・外観あり|55.84%|

中心線だけの対応診断では14.89→27.77%、最小支持点数も45→12にすると28.57%。現行推論は閾値や乱数規則も異なるため27.57%になる。27.57→42.91%には教師・学習率推移・遮蔽再抽選などの学習条件一式が含まれ、教師単独の寄与は未分離。42.91→56.74%の+13.84 ppは、外観・教師・推論・遮蔽・最適化を揃えた投影追加の対照である。この比較順に条件付く差であり、独立な要因の寄与として足し合わせない。

元1194M trainの内周長径は99.57〜143.57 px、多様形状testは13.93〜88.74 px。追加投影は24.20〜179.02 pxまで広げる。多様形状通常画像の長径24 px未満44例では、旧帯1成功、旧CNN＋現行推論10成功、現行学習・投影なし15成功、投影あり27成功だった。点群処理だけでは埋まらないサイズ範囲への対応に、投影学習が寄与している。投影要因には位置・扁平率・視点に伴う陰影も含み、サイズ単独の効果とはしない。

多様形状学習の投影のみの悪化は、120epochまでの延長では解消しなかった。

|多様形状学習の構成|1194M・60epoch予算|1194M・120epoch予算|
|---|---:|---:|
|拡張なし|43.20%|46.22%|
|投影のみ|40.80%|43.41%|
|投影＋外観|70.95%|69.78%|

投影のみは+2.61 pp回復したが、拡張なしも+3.02 pp改善した。同予算での投影のみの差は−2.40→−2.82 ppで残る。学習延長の効果は認める一方、今回の予算範囲では「投影のみが悪い理由は単なる学習不足だけ」とは説明できない。投影＋外観は60epochでも投影のみ120epochを上回り、外観の効果を学習時間だけで代替できていない。120epoch以降や他seedの結果までは保証しない。

追加投影validationの120epoch結果では、投影のみは元材質でloss0.2525（拡張なし0.5965）まで適合したが、同じ投影で外観を変えると0.6760に悪化した。投影＋外観は元材質0.2755、外観変更0.3521。735組のsample ID・ラベルhash・欠損条件の一致を確認済み。これは「投影画像そのものをまだ学べていない」だけでなく、外観が変わった場合への対応不足が残るという解釈を支持する。CNN内部のどの手掛かりに依存したかは未測定で、悪化の唯一の機構を証明したとはしない。外観は模様と平均反射色・明暗を含む一式である。

研究で示す簡潔な答えは、**未知PAFへの転移には、形状の多様化だけでなく、内周の投影と外観の偏りを減らす学習が重要である。** 中心線化を含む共通推論を前提とし、PAF概念の獲得そのものを証明したとは言わない。

## 対応比較

1. 旧main構成の1194M学習CNNを固定し、同じ確率画像へ帯/中心線×最小45/12点を適用する。閾値0.35・他のRANSAC条件は固定する。さらに現行推論（閾値0.5・中心線12点・現行乱数・一様画像棄却）でも採点する。
2. 現行1194M学習の元材質・投影あり・開口幅遮蔽を基準に、投影だけを外す。教師・遮蔽・最適化・初期化・60epochは固定。4スロット抽選を[0,0,0,0]へ写し、抽選回数は維持する。
3. 多様形状学習の拡張なし・投影のみ・投影＋外観を、同じ初期化から各120epoch学習する。60epochでoptimizerをリセットしない。60/120epochまでの元多様形状validation loss最小重みをそれぞれ保存し、両testで採点する。以前の投影のみの対照と同じ固定遮蔽を用い、開口幅遮蔽は3構成とも使わない。

通常と遮蔽・白飛び・黒つぶれの全4強度を評価する。成功はIoU≥0.8、全画像を分母に含む。予算延長による改善と、同予算の構成間の差を分ける。元学習分布でのvalidation改善だけを、1194Mへの汎化改善と同一視しない。

学習不足仮説は、投影のみの60→120epochの変化に加え、同じ120epochの拡張なしとの差が解消するかで判断する。学習・validation lossが下がっても1194M転移が回復しない場合、少なくともこの予算範囲では学習不足だけで悪化を説明できない。拡張画像への適合は追加投影validationで別に確認する。120epochを普遍的な収束保証とはしない。

## 実装と再現

`run.py`はデータの対応写像と保存先を指定し、既存の共通学習ループ・教師・CNN・推論を呼ぶ。履歴保存時に60/120epochまでの最良重みをコピーするので、最適化の更新処理は変更しない。以前の学習と先頭60epochの損失・選択重みを照合する。

`validation.py`は元/追加投影のサイズ・位置・軸比を元ラベルから測る。追加投影validationの元材質/外観変更で境界lossを測り、拡張された分布への適合を事後診断する。この追加validationで重みを選び直さない。

`report.py`は全推定を元GTで再計算し、条件別表、固定CNNの点群診断、予算間の対応差、学習曲線と比較図を保存する。旧帯45点の保存推定も全件再現する。

```powershell
.venv/Scripts/python.exe -X utf8 research/paf_training_diagnosis/run.py prepare
.venv/Scripts/python.exe -u -X utf8 research/paf_training_diagnosis/run.py run
.venv/Scripts/python.exe -X utf8 research/paf_training_diagnosis/validation.py
.venv/Scripts/python.exe -X utf8 research/paf_training_diagnosis/report.py
```

保存先は`output/paf_training_diagnosis_v1/`。plan.jsonが設定・実装・入力・参照モデルを固定する。以前のモデル・集計は上書きしない。

## 解釈の制約

- 旧CNNの現行推論から現行学習・投影なしへの差には、教師・学習率推移・遮蔽再抽選などが含まれる。教師だけの効果と断定しない。
- 1194Mでの外観除去の結果から、多様形状学習でも外観が不要だとは結論しない。元の材質・投影・形状分布と転移方向が違う。
- GPU学習は決定的アルゴリズムを指定しておらず、同じseedでも過去の重み・履歴の完全一致は保証しない。同じ初期重み・固定batchの短い2反復で数値差を確認する入口は`validation.py --numerical-repeat-only`。学習時間の効果は今回の一続きの学習内で60/120epochを比較する。
- 1seedの探索的対照。120epochでの結果は、他seedやさらに長い学習での結果を保証しない。学習lossは入力分布が異なるため、構成間の絶対値だけで学習不足と断定しない。
- 既存testは参照済み。黒背景・単一開口CGでの結果であり、任意機体・実画像への汎化やPAF概念の獲得の証明ではない。
